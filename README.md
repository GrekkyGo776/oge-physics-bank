# Банк заданий ОГЭ по физике

Задания из открытого банка ФИПИ (https://oge.fipi.ru/bank/), демоверсий ОГЭ 2017–2027 и сборников
«ОГЭ. Физика. Типовые экзаменационные варианты» Е. Е. Камзеевой (2024–2026, с разрешения автора),
разложенные по разделам и темам КЭС, типам ответа и номерам заданий КИМ ОГЭ. Можно решать задания
с проверкой ответа, собирать и печатать варианты с ключом ответов. Задания из сборников можно
убрать меткой «Сборники Камзеевой» в фильтре «Источник заданий» — тогда останутся только материалы ФИПИ. Сайт бесплатный.
